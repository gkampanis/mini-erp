# Βελτίωση αλληλεπίδρασης

Η εφαρμογή παραμένει εργαλείο προετοιμασίας EBS. Η αναφορά στο βιβλίο
*Designing Interfaces*, 3η έκδοση (Tidwell, Brewer, Valencia, O’Reilly, 2020),
αφορά επιλεγμένα σχετικά μοτίβα, όχι αναπαραγωγή του βιβλίου ή προσθήκη λειτουργιών.

| Σχετική αρχή | Εφαρμογή Mini ERP |
| --- | --- |
| Two-Panel Selector / Split View, έντυπη σ. 341 | Στοιχεία/προετοιμασία αριστερά και αρχικό PDF δεξιά, με μετακινούμενο διαχωριστικό. |
| Preview, σ. 404 | Έλεγχος αντιστοίχισης, ποσών και εξαιρέσεων πριν από επιβεβαίωση εισαγωγής. Ουρά RPA πριν την έναρξη. |
| Responsive Enabling / Progressive Disclosure, σ. 224 | Εμφάνιση ρύθμισης προβολής PDF όταν λείπει το πρόσθετο. Αποτροπή δεύτερης εισαγωγής κατά την εργασία. |
| Forgiving Format, σ. 477 | Ποσά με επιπλέον δεκαδικά στρογγυλοποιούνται με ROUND_HALF_UP, χωρίς αλλαγή αρχικής γραμμής. Πραγματικές ασυμφωνίες χρειάζονται έλεγχο. |
| Cancelability, σ. 415 | Ακύρωση προεπισκόπησης χωρίς αποθήκευση. Παύση/διακοπή RPA μετά την τρέχουσα προσπάθεια. |

Η ακύρωση δεν παρουσιάζεται ως αναίρεση ήδη πληκτρολογημένων πεδίων EBS.
Αβέβαιη προσπάθεια παραμένει προς χειροκίνητο έλεγχο, χωρίς αυτόματο replay.
Η εγκατάσταση πρόσθετων και η λήψη από HTTPS είναι ξεχωριστές, ρητές ενέργειες.
Η λήψη PDF δεν διαθέτει ακόμη κουμπί ακύρωσης στη διάρκεια της λήψης· έχει timeout
και ανώτατο μέγεθος. Δεν δηλώνεται ότι υλοποιήθηκαν όλες οι αρχές του βιβλίου.

## Αναφορά Legend

Εξετάστηκε το https://github.com/gkampanis/legend στο commit
`b4f29864df37c92b5ce00071c2f457a263ab8092`. Πρόκειται για οργάνωση τοπικών
αρχείων. Αξιοποιήθηκαν ιδέες προεπισκόπησης, ατομικής αντιγραφής,
μη αντικατάστασης πρωτοτύπων και προσαρμογής DPI στα Windows.
Δεν περιέχει μηχανισμό λήψης τιμολογίων από ΑΑΔΕ. Δεν προστέθηκαν άσχετες
λειτουργίες οργάνωσης φακέλων.

## Όρια νέων συνδέσεων

- PDF: τοπική σύνδεση ή ρητή λήψη δημόσιου HTTPS PDF, αρχειοθέτηση με SHA-256,
  διαφορετικός τύπος για τιμολόγιο και δελτίο αποστολής. Δεν γίνεται αυτόματη
  λήψη PDF μέσω AADE API.
- myDATA: παράθυρο API username/subscription key ανά εταιρεία/περιβάλλον.
  Στα Windows χρησιμοποιείται Credential Manager. Δεν αποθηκεύονται μυστικά
  σε SQLite, αρχεία ρυθμίσεων ή audit. Δεν χρησιμοποιούνται κωδικοί TAXISnet.
  Η επίσημη σελίδα τεχνικών προδιαγραφών αποκλείστηκε από το δικτυακό proxy
  του cloud κατά την έρευνα· δεν δηλώνεται τρέχουσα πιστοποίηση endpoints
  ή ζωντανή δοκιμή REST. Σύνδεσμος οδηγιών παρέχεται στο παράθυρο ρύθμισης.
- RPA: προσομοίωση και προαιρετική συμπλήρωση των πέντε πεδίων ΤΕΔ εξόδου,
  μόνο σε Windows, με mapper και ρητό πιλοτικό έλεγχο. Η πραγματική ροή
  αφορά ομάδα 6, δεν πατά Save, δεν δημιουργεί αυτόματα νέο ΤΕΔ και παύει
  μετά από κάθε προσπάθεια. Η ομάδα 2 χρειάζεται ξεχωριστή επαληθευμένη ροή.
  Τα native Windows Credential Manager, SendInput/Unicode και EBS controls
  απαιτούν έλεγχο στο πραγματικό Windows/EBS περιβάλλον.
