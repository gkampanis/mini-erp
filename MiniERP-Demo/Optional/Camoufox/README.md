# Προαιρετική ανάκτηση PDF με Camoufox

Εγκατάσταση από Ρυθμίσεις → PDF και λήψεις → Εγκατάσταση Camoufox.
Ο browser και η χωριστή Python εγκαθίστανται εδώ, σε υποφάκελο ανά έκδοση Python.
Το ZIP περιέχει την υποδομή εγκατάστασης, όχι τον browser 1,31 GB.
Απαιτούνται Windows x64, internet, δικαίωμα εγγραφής και 7 GB ελεύθερα για εγκατάσταση.
Δεν χρειάζεται να εγκαταστήσεις άλλη Python χειροκίνητα.
Μετά την εγκατάσταση γίνεται δοκιμή εκκίνησης πριν ενεργοποιηθεί η επιλογή.
Για ανάκτηση: ΑΑΔΕ / myDATA → Ληφθέντα / Εκδοθέντα / PDF →
Ανάκτηση εκκρεμών με Camoufox. Πρώτα κάνε κανονική λήψη PDF.
Χρησιμοποιείται χωριστό profile ανά εταιρεία και περιβάλλον. CAPTCHA από εσένα.
Η εκτύπωση HTML σε PDF παραμένει στον υπάρχοντα Chromium.
Μην μεταφέρεις κωδικούς ή δεδομένα σε αυτόν τον φάκελο.
