# Mini ERP · Συνδεδεμένη ροή / έξοδα προς EBS

[Λήψη νέας ελεγμένης έκδοσης](https://github.com/gkampanis/mini-erp/raw/refs/heads/downloads/MiniERP-Expenses-20261022-103909.zip)

Αποσυμπίεσε όλο το ZIP και άνοιξε **ANOIGMA_MINI_ERP.bat** με την υπάρχουσα Python 3.12+.
Η προηγούμενη βάση διατηρείται χωρίς επανεισαγωγή συνθετικών παραστατικών.

Μία εισαγωγή Excel, ενιαία λίστα εργασίας, καρτέλες με σταθερό κωδικό/επωνυμία/ΑΦΜ,
αποθηκευμένοι λογαριασμοί 2/6, μαζική έγκριση, read-only ληφθέντα/εκδοθέντα myDATA,
ξεχωριστοί ειδικοί κωδικοί Μητρώου, PDF και adapter από myInvoices 36a1539.

**Στο EBS καταχωρούνται μόνο εγκεκριμένα έξοδα ομάδας 6.** Οι αγορές ομάδας 2
παραμένουν για διαχωρισμό προμηθευτών και παραστατικών και εξαιρούνται από την ουρά.
Οι λογαριασμοί καρτέλας εμφανίζονται ως προτάσεις πριν μαζική έγκριση.

Πέρασαν 70 backend/tool tests και 15 GUI regressions στον source και στο αποσυμπιεσμένο
ZIP, καθώς και actual Tk/Chromium synthetic smoke και έλεγχοι αναβάθμισης/διατήρησης δεδομένων.
Native Windows, πραγματικό EBS, πραγματικοί κωδικοί ΑΑΔΕ/Μητρώου και πραγματικοί πάροχοι: NOT_RUN.
Πριν batch απαιτείται δοκιμή ενός εξόδου και επιβεβαίωση πραγματικής αποθήκευσης στο EBS.
Save/νέο ΤΕΔ δεν βαφτίζονται database confirmation. Δεν υπάρχει αυτόματη διαβίβαση myDATA.

Η συνοδευτική αναφορά και το SHA-256 αντιστοιχούν στο συγκεκριμένο αρχείο.
