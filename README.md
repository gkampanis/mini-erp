# Mini ERP · Ενιαία προετοιμασία παραστατικών για EBS

Ελληνική τοπική εφαρμογή Windows/Python/SQLite. Το Excel φορτώνεται μία φορά.
Οι ίδιες εγγραφές χρησιμοποιούνται για καρτέλες αντισυμβαλλομένων, έλεγχο
λογαριασμών, συμφωνία ΑΑΔΕ, PDF και ελεγχόμενη εκτέλεση EBS.

## Εκκίνηση

Αποσυμπίεσε ολόκληρο το πακέτο και άνοιξε **ANOIGMA_MINI_ERP.bat**.
Χρησιμοποιεί την υπάρχουσα Python 3.12+ με Tk/SQLite και διατηρεί διαγνωστικό log.
Η κανονική εκκίνηση δεν εισάγει συνθετικά παραστατικά. Αν υπάρχει προηγούμενη
βάση στο `%LOCALAPPDATA%\MiniERP\Demo`, την ανοίγει χωρίς νέα εισαγωγή· αλλιώς
χρησιμοποιεί `%LOCALAPPDATA%\MiniERP\Data`. Δεν διαγράφει ή μετακινεί δεδομένα.
Η εντολή `python -m app --data-dir <φάκελος>` ανοίγει συγκεκριμένη βάση.

## Καθημερινή εργασία

1. Εισαγωγή Excel → έλεγχος αντιστοίχισης και εξαιρέσεων → επιβεβαίωση.
   XLSX/XLSM, ποσά Decimal σε ακέραια cents, ROUND_HALF_UP, αμετάβλητη προέλευση,
   SHA-256 και audit. Διπλότυπα δεν ξαναδημιουργούνται. Γνήσιες ασυμφωνίες
   παραμένουν προς έλεγχο· δεν εξαναγκάζονται λογιστικά να συμφωνήσουν.
2. «Αντισυμβαλλόμενοι»: μία καρτέλα ανά εταιρεία/ΑΦΜ με σταθερό κωδικό,
   επωνυμία και πολλαπλούς ρόλους προμηθευτή/πιστωτή/πελάτη. Προαιρετικοί
   λογαριασμοί αγορών ομάδας 2 και εξόδων ομάδας 6, με συνήθη ομάδα.
   Συμπληρώνονται στις επόμενες εγγραφές ως προτάσεις, χωρίς αυτόματη έγκριση.
3. «Λογαριασμοί & έγκριση»: κοινός λογαριασμός ή λογαριασμοί ανά ΑΦΜ,
   προτάσεις από εγκεκριμένο ιστορικό και μαζική έγκριση της συγκεκριμένης λίστας.
   Δεν χρειάζεται πληκτρολόγηση και άνοιγμα κάθε παραστατικού χωριστά.
4. «ΑΑΔΕ / myDATA»: πραγματικό ΑΦΜ εταιρείας, ασφαλής αποθήκευση API κωδικών,
   έλεγχος σύνδεσης, RequestDocs ληφθέντων και RequestTransmittedDocs εκδοθέντων.
   Αρχική περίοδος ο προηγούμενος μήνας. Τα δεδομένα ΑΑΔΕ συμφωνούνται με MARK
   και στοιχεία/ποσά Excel. Άγνωστα εμφανίζονται χωριστά, χωρίς σιωπηρή μετατροπή
   σε τοπικά τιμολόγια ή διπλές εγγραφές. Ακυρώσεις είναι παρατηρήσεις για έλεγχο,
   όχι αυτόματη ακύρωση/διαγραφή τοπικού παραστατικού.
5. «Λήψη PDF»: επίσημο downloadingInvoiceUrl, άμεση λήψη ή επιλεγμένος
   μηχανισμός myInvoices v0.13 για δυναμικούς παρόχους. Αν χρειάζεται ανθρώπινος
   έλεγχος, «Ανάκτηση εκκρεμών» ανοίγει ξεχωριστό ορατό browser. Δεν παρακάμπτεται
   CAPTCHA. Αρχειοθέτηση ανά ΑΦΜ εταιρείας/μήνα/MARK, χωρίς overwrite. Συμφωνημένο
   PDF συνδέεται αυτόματα με το ίδιο τοπικό παραστατικό και εμφανίζεται στο διπλό
   κλικ. PDF εκτύπωσης διακρίνεται από αρχικό PDF και δεν θεωρείται επαληθευμένο.
6. «Ρυθμίσεις EBS»: ορισμός mapper, Save και Νέο ΤΕΔ μία φορά. Πιλοτική
   καταχώριση μίας εγγραφής, έλεγχος πραγματικής αποθήκευσης στο EBS και ρητή
   επιβεβαίωση από «Ιστορικό / έλεγχος EBS». Έπειτα επιτρέπεται batch στην
   υποστηριζόμενη ροή ΤΕΔ ομάδας 6. Συμπλήρωση → Save → νέο ΤΕΔ, παύση κάθε 40,
   επιλεγμένη γραμμή συμπεριλαμβανόμενη και stop σε αβέβαιη κατάσταση.
   Η ομάδα 2 έχει καρτέλα/λογαριασμό/προετοιμασία· η πραγματική φόρμα της δεν
   ενεργοποιείται πριν διευκρινιστεί και ελεγχθεί.

## Επωνυμία από ΑΦΜ

Στην καρτέλα αντισυμβαλλομένου υπάρχει «Άντληση στοιχείων από ΑΦΜ» μέσω της
ξεχωριστής επίσημης SOAP 1.2 υπηρεσίας Μητρώου RgWsPublic2. Χρησιμοποιεί
**ειδικούς κωδικούς Μητρώου**, διαφορετικούς από myDATA/TAXISnet.
Η προεπισκόπηση απαιτεί επιβεβαίωση πριν ενημέρωση της ίδιας καρτέλας.
Κωδικός, ΑΦΜ, λογαριασμοί και αρχικές γραμμές Excel διατηρούνται.

## Προστασία και όρια

Οι κωδικοί αποθηκεύονται μόνο στο Windows Credential Manager, χωριστά ανά
εταιρεία, υπηρεσία και περιβάλλον. Δεν γράφονται σε SQLite, source ή audit.
Δεν υπάρχει fallback σε plaintext. Η SQLite/XML/PDF περιέχουν επαγγελματικά
δεδομένα και χρειάζονται ιδιωτικό τοπικό φάκελο· ενεργή βάση όχι σε SMB/NAS.
Ο αρχικός EBS Agent παραμένει ανεξάρτητος και αμετάβλητος.

Δεν υπάρχει αυτόνομη λογιστική ταξινόμηση, διαβίβαση/ακύρωση myDATA ή direct
EBS DB write. Το Save και το νέο ΤΕΔ δεν αποτελούν επιβεβαίωση database commit.
Αβέβαιες προσπάθειες δεν επαναλαμβάνονται αυτόματα. Τα συνθετικά demo δείγματα
δεν επιτρέπονται στην πραγματική νέα ροή EBS. Δεν έχει εκτελεστεί native Windows,
ζωντανό EBS, Μητρώο ή myDATA με πραγματικούς κωδικούς στο cloud.

## Ανάπτυξη / επαλήθευση

Η εισαγωγή/βάση χρησιμοποιεί standard library. PDF: `requirements-pdf.txt`.
Δυναμικοί πάροχοι: `requirements-browser.txt` και Chromium. Πραγματικό Windows
RPA: `requirements-rpa.txt`. Τα σχετικά κουμπιά εγκαθιστούν πρόσθετα σε χωριστό
φάκελο MiniERP μόνο μετά από επιβεβαίωση.

```powershell
py -3.12 -m pip install -r requirements-browser.txt
py -3.12 -m playwright install chromium
py -3.12 scripts/verify_delivery.py --require-windows
```

Για ελεγχόμενα συνθετικά δεδομένα: `python -m app.demo --data-dir <ξεχωριστός φάκελος>`.
Πριν από κάθε παράδοση εφαρμόζεται το [delivery gate](docs/ECC_DELIVERY.md).
Δείτε [συνδεδεμένη ροή και πηγές](docs/CONNECTED_WORKFLOW.md),
[αρχικό audit](docs/AUDIT.md), [schema](docs/SCHEMA.md), [QA](docs/QA.md).
