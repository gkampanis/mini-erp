# Mini ERP — Προετοιμασία παραστατικών για EBS

Ελληνικό desktop για **Excel → Έλεγχος → Βάση → Προετοιμασία ομάδας/λογαριασμού → Μελλοντική εισαγωγή στο EBS**. Λειτουργεί ανεξάρτητα για την προετοιμασία, ενώ το EBS παραμένει το κύριο ERP. Η παρούσα έκδοση δεν στέλνει δεδομένα στο EBS/myDATA και δεν παράγει λογιστικές εγγραφές.

## Εκκίνηση

Python 3.12+ με Tkinter και SQLite. Δεν απαιτούνται τρίτα Python packages. Στα Windows εγκαταστήστε Python από python.org με Tcl/Tk. Σε Linux χρειάζεται διαθέσιμο display και Tkinter του Python runtime.

```powershell
cd mini-erp
py -3.12 -m unittest discover -s tests -v
py -3.12 -m app.demo
```

Το demo δημιουργεί αποκλειστικά συνθετικά δεδομένα στο `.local/demo`: δύο διαφορετικά Excel layouts, τρία τιμολόγια, τρεις προμηθευτές και μία απορριπτέα γραμμή. Αρνείται υπάρχοντα φάκελο βάσης χωρίς demo marker. Επαναληπτική εκτέλεση δεν διπλασιάζει παραστατικά.

Για κανονική κενή βάση:

```powershell
py -3.12 -m app --data-dir C:\MiniERP-data
```

Στην πρώτη εκκίνηση δηλώνετε εταιρεία (ΑΦΜ ως κείμενο και επωνυμία). Στο Linux οι αντίστοιχες εντολές χρησιμοποιούν `python`. Προτιμήστε τοπικό δίσκο για βάση και sources, όχι ενεργή SQLite σε SMB/NAS.

## Χρήση

1. «Εισαγωγή Excel»: αναγνωρίζει XLSX/XLSM, ανεξάρτητα από σειρά στηλών.
2. Ελέγξτε mapping και preview. Άγνωστες/διφορούμενες στήλες διορθώνονται από τα πεδία αντιστοίχισης και επανελέγχονται πριν επιβεβαίωση.
3. Υποχρεωτικά ΑΦΜ, ημερομηνία, καθαρή, ΦΠΑ και αριθμός ή ενιαίος αριθμός. MARK προαιρετικό. Σειρά/αριθμός διατηρούνται ξεχωριστά. Το gross μπορεί να προκύψει από net + tax χωρίς υπολογισμό φορολογικού συντελεστή.
4. Επιβεβαιώστε την εισαγωγή. Οι εξαιρέσεις εμφανίζονται στην πλήρη αναφορά και αποθηκεύονται στο job. Διπλότυπα παραλείπονται, conflicts κρατούνται για έλεγχο χωρίς overwrite.
5. Αναζητήστε με ΑΦΜ, επωνυμία, ημερομηνία, σειρά, αριθμό ή MARK. Ταξινομήστε από τις επικεφαλίδες και φιλτράρετε ανά ομάδα και τοπική προετοιμασία.
6. Διπλό κλικ για καρτέλες Στοιχεία / Προετοιμασία EBS / Προέλευση / Ιστορικό. Στην προετοιμασία επιλέγετε ομάδα 2 (αγορές) ή 6 (έξοδα), τον δικό σας λογαριασμό και επιβεβαιώνετε ρητά τον έλεγχο. Η απόφαση αποθηκεύεται ξεχωριστά από τα αρχικά δεδομένα με audit πριν/μετά. Δεν προκύπτει αυτόματος κανόνας μόνο από ΑΦΜ.
7. Από «Έλεγχοι εισαγωγής» ανοίγετε ξανά αποθηκευμένες αναφορές, εξαιρέσεις και προειδοποιήσεις. Ίδιος αριθμός με διαφορετική ημερομηνία στο ίδιο έτος επισημαίνεται ως πιθανό διπλότυπο χωρίς merge/overwrite.

Η παρούσα έκδοση εισάγει εισερχόμενα τιμολόγια EUR. Η τοπική έγκριση προετοιμασίας διακρίνεται από την εισαγωγή και από οποιαδήποτε πραγματική EBS καταχώριση. Ο έλεγχος λογαριασμού είναι συντακτικός και ως προς την ομάδα, όχι έλεγχος του λογιστικού σχεδίου EBS. Αρχεία .xls χρειάζονται εξωτερική μετατροπή. Formula rows απορρίπτονται, macros δεν εκτελούνται, ΑΦΜ δεν συμπληρώνονται αυτόματα. Ο έλεγχος ΑΦΜ είναι μορφολογικός, όχι επαλήθευση στο φορολογικό μητρώο. Περιορισμοί: 20 MB compressed, 64 MB expanded XML, 20.000 γραμμές/φύλλο, 200 cells/γραμμή.

Η πρώτη τομή δεν είναι ολόκληρο το Phase 1. PDF/δελτίων archive, editing μητρώου, ελεγμένοι εταιρικοί κανόνες/approved mappings, exports και ασφαλής EBS connector είναι επόμενα milestones. Η χειροκίνητη προετοιμασία ανά παραστατικό και τα φίλτρα ομάδας/έγκρισης έχουν υλοποιηθεί. myDATA, EBS, journal και έκδοση παραστατικών δεν έχουν υλοποιηθεί. Δεν γίνεται ισχυρισμός φορολογικής συμμόρφωσης. Το αρχικό EBS source διατηρείται ανέπαφο εκτός repository στο `/workspace/reference-handoff` του παρόντος cloud workspace.

## Git / κυκλοφορίες

Το νέο repository είναι ανεξάρτητο από τον EBS Agent. `main` για baseline και `feature/*` για λειτουργίες. Τοπικά tags μόνο για ελεγμένα releases. Κανένα push ή δημόσια διάθεση χωρίς έγκριση και έλεγχο άδειας/δεδομένων.

Στο παρόν cloud χρησιμοποιήστε `/usr/bin/python3 -m app.demo` με διαθέσιμο `DISPLAY` για σωστή απόδοση ελληνικών. Δείτε επίσης το [schema roadmap](docs/SCHEMA.md) και τα [screenshots της εκτελεσμένης εφαρμογής](docs/screenshots/documents.png).

## Έλεγχος πριν από ZIP

Το [Mini ERP Delivery Check](docs/ECC_DELIVERY.md), εμπνευσμένο από το ECC, εκτελεί τους ελέγχους και δοκιμάζει το ίδιο το συσκευασμένο πρόγραμμα πριν παραγάγει ελεγμένο ZIP:

```powershell
py -3.12 scripts\verify_delivery.py --require-windows
```

Στο cloud: `DISPLAY=:99 /usr/bin/python3 scripts/verify_delivery.py`. Τα αποτελέσματα Linux δεν χαρακτηρίζονται ως Windows acceptance. Το τελικό ZIP περιέχει verification report και έχει εξωτερικό SHA-256. Αποτυχία υποχρεωτικού ελέγχου μπλοκάρει τη νέα παράδοση. Δεν απαιτούνται πρόσθετα runtime packages για την εφαρμογή.


## Εκκίνηση Windows με διαγνωστικά

Στο ZIP κάντε αποσυμπίεση όλων των αρχείων και διπλό κλικ στο `ANOIGMA_MINI_ERP.bat`. Ο launcher χρησιμοποιεί την υπάρχουσα Python (`py -3`, αλλιώς `python`), διατηρεί ανοικτή την κονσόλα και γράφει log στο `%LOCALAPPDATA%\MiniERP\Logs`. Ο Python bootstrap ελέγχεται πλέον από το delivery gate και στον source και στο ZIP. Η εκτέλεση των Windows BAT/CMD παραμένει ξεχωριστή αποδοχή Windows. Για παράκαμψη CMD: `py -3 START_DEMO.py` από τον φάκελο του προγράμματος.
